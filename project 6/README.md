# 8×1 Multiplexer Using Verilog

## Project Title
Design and Simulation of an 8×1 Multiplexer Using Verilog HDL

## Introduction

A Multiplexer (MUX) is a combinational digital circuit that selects one input from multiple inputs and sends it to a single output.

An 8×1 Multiplexer has:

- 8 data inputs: I0, I1, I2, I3, I4, I5, I6, I7
- 3 select lines: S2, S1, S0
- 1 output: Y

Since there are 8 inputs:

2³ = 8

Therefore, 3 select lines are required.

## Objective

The main objectives of this project are:

1. To design an 8×1 Multiplexer using Verilog HDL.
2. To understand the operation of select lines.
3. To write a Verilog testbench.
4. To simulate the design.
5. To verify the output for all select-line combinations.
